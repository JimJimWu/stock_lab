# 🐎 秉諺的黑馬雷達 (BlackHorse Radar) V43.1

> **專為台股打造的機構級 AI 自動化量化雷達・戰情儀表板與回測決策系統**  
> 核心哲學：**「技術籌碼抓動能・跨年毛利護長線・雙管齊下防雜訊・分批建倉控風報」**

---

## 📌 系統架構全景

本系統採模組化分散式架構，前端具備 Streamlit 視覺化戰情操控中心，後端結合 GitHub Actions 實現無人值守定時背景掃描，並深度串接 Discord Webhook 與 Google Gemini 2.5 Flash 決策引擎：

*   **`app.py`**: Streamlit 網頁戰情儀表板主程式 (V43.1 雙軌雲端持久化版)
*   **`auto_scan.py`**: 背景無人值守自動掃描推播引擎 (V36.3)
*   **`backtest_processor.py`**: 多週期量化未來績效自動回補引擎 (V6.2 後綴免疫版)
*   **`signal_history.csv`**: 歷史觸發訊號資料庫 (原始底層紀錄)
*   **`signal_history_backtest.csv`**: 多週期 (T+1 ~ T+20) 實際報酬率回測資料庫
*   **`watchlist.json`**: 核心重點觀察名單 (與雲端自動同步)
*   **`industry_db.json`**: AI 深度企業百科與產業價值鏈資料庫 (與雲端自動同步)
*   **`.github/workflows/auto_run.yml`**: GitHub Actions 盤中/盤後定時自動排程

## 🎯 五大核心量化戰術訊號

系統以 5MA、20MA、60MA、240MA、RSI(14)、MACD 及三大法人主力資金流向為基礎，自動識別 5 大關鍵技術與籌碼型態：

| 戰術訊號 | 量化觸發條件 | 主力行為解密 | 建議操盤紀律 |
| :--- | :--- | :--- | :--- |
| **🚨【強勢突破】** | 量比 >= 1.15 倍 ＋ 近 5 日主力籌碼無倒貨 | 量能爆發、籌碼健康，多方主力發起攻擊波。 | 順勢追價短打，T+1～T+3 見高分批停利；若月線乖離率 > 15% 嚴禁追高。 |
| **💎【大戶惜售】** | 量比 < 0.7 倍極致量縮 ＋ 站穩 5MA ＋ RSI >= 50 | 浮額沉澱、主力鎖碼，散戶籌碼清洗徹底。 | 假突破機率極低，適合持股波段抱牢（T+5～T+10）。 |
| **🔥【低檔底背離】** | 股價創 10 日新低 ＋ RSI 拒絕破底且 RSI < 40 | 空方力道衰竭，大戶於破底恐慌中默默低吸。 | 左側反轉強彈點，密切鎖定 T+3～T+5 均線乖離收斂之黃金獲利期。 |
| **🐉【深水區潛龍】** | 回測 60MA/240MA（誤差 <= 5%）＋ 量縮 ＋ RSI <= 35 | 測試長線莊家成本線且無大戶出貨。 | 安全低接位階，停損空間小、波段盈虧比（R/R）極佳。 |
| **💀【出貨陷阱】** | 成交量爆量（>= 1.15 倍）但近 5 日主力大倒貨 | 高檔假突破真出貨，誘多單追高套牢。 | 嚴禁接刀追高；持有者應逢高拔檔避險。 |

## 📈 V42.2 策略多週期勝率模擬分析儀

從單純的「訊號觸發」，進化為能以歷史數據佐證勝率的「量化決策輔助系統」：
*   **連續鎖碼偵測中心**：過濾出最近 N 個交易日連續出現相同核心訊號的強勢股，徹底消滅單日假突破。
*   **T+1 ~ T+20 交叉勝率圖**：動態視覺化不同訊號在多個持有週期下的歷史實際勝率，提供精確的波段長度指引。

## 🛡️ 跨年度毛利率護城河與 Q1 逆風容錯機制

傳統單季營收濾網容易在 Q1 淡季因短期庫存調整而誤殺長線優質好股。系統導入**「跨年度財報序列雙軌檢測引擎」**：

1.  **長線結構性成長檢驗**：計算近 3～4 年營業毛利率與年度營收。若毛利率向上且營收正成長，賦予長線基本面加權。
2.  **Q1 單季逆風容錯（免死金牌）**：若單季營收回檔，只要跨年毛利與營收維持擴張，即判定為 `💎 長線成長・單季逆風黃金坑`。
3.  **金融特許行業專屬通道**：針對 28XX / 58XX 金控股（會計無營業毛利科目），自動判定整體獲利穩健度，標記為 `🏛️ 金融特許・獲利穩健`。

## ⚙️ V42.1 黑科技：自體季報反算引擎

為了解決 Yahoo Finance 國際資料庫對台灣中小型股 (OTC) 財報經常性缺漏的問題，系統獨創「自體反算引擎」：
*   當偵測到 EPS、ROE 或 PE 欄位為 N/A 時，系統將自動調閱該公司的原始資產負債表與損益表，精準反算 TTM 數值，確保基本面濾網不漏接任何一檔黑馬。

## ⚖️ 雙管齊下推播與 3-3-4 資金控管

*   **綜合火力評分**：籌碼 (50%) + 量能 (35%) + 毛利成長加權 (15%)。
*   **精華推播管制**：每日僅推播總分 **>= 25.0 分** 且名列當日 **Top 5** 之標的，其餘全數寫入 CSV 留存回測。
*   **3-3-4 分批佈局法**：5MA 試單 30%、20MA 加碼 30%、60MA/莊家防線重倉 40%；收盤實質跌破莊家防守線 3% 鐵血停損。
