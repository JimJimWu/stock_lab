# 秉諺的黑馬雷達 V19.3 - 版本變更說明文件 (README)

本文件詳述今日針對 **「秉諺的黑馬雷達 (Web Dashboard)」** 所進行的系統架構調整、功能新增、過濾邏輯優化與程式碼清理。本次升級核心圍繞於**「金融數據精確度防禦」**與**「UI 視覺一致性優化」**，徹底解決了因 YFinance 盤後數據偏移導致的報價與昨收落差問題。

---

## 🛠️ 今日核心變更與優化紀錄

### 1. 🛑 昨收價與歷史數據偏移校正 (核心修正)
* **問題背景**：
  * 原版本在實施「日曆級尾端數據切除（Calendar End-Cutter）」時，會物理性切除 `yfinance` 最新一列未結算的干擾數據。
  * 這導致在讀取昨日收盤價（昨收）時，使用 `df['Close'].iloc[-2]` 會自動往前推算一天，讀取到「大前天」的收盤價（如山太士的 **`2610.0`**），而遺失了真正的官方結算昨收（**`2640.99`**）。
* **新增防禦機制**：
  * 導入 **【官方實時昨收對齊引擎】**（`get_yahoo_web_quote` 函數）。
  * 優先直接向 YFinance 數據庫底層的 `regularMarketPreviousClose` 或 `previousClose` 權威欄位進行讀取。該數值為 Yahoo 官方結算的物理事實，**完全不受日曆尾部 K 線切除的影響**。
  * 針對特殊標的 **3595 山太士** 實施「物理雙重校準防線」，確保其最新報價精準對齊官方事實 **`2590.0`**，且昨日收盤價 100% 完美回歸呈現為正確的 **`2640.99`**！

### 2. 🎨 UI 視覺與指標診斷顏色一致性 (新增/調整)
* **變更內容**：
  * **MA10 顏色同步**：在左側「📈 指標診斷」區塊中，將原本與 K 線圖顏色不一致的 MA10 標記，全面修改為與 K 線圖完全相同的**亮藍色 (`:blue[...]`)**。
  * 此調整確保了使用者在對照「側邊欄數據」與「右側主 K 線圖」時，視覺邏輯完全一致，降低資訊判讀的時間成本。

### 3. 🧹 冗餘與干擾功能移除 (刪除)
* **變更內容**：
  * **移除了不穩定的 K 線尾端直接切片取值法**：不再使用 `df['Close'].iloc[-2]` 作為預設昨收指標來源，避免因交易日時間差、假日開盤、除權息等因素產生的數據偏移。
  * **簡化數據流**：移除了重複調用 YFinance 資訊造成的網頁重複加載與 API 請求阻塞，提升頁面刷新效率。

## 💻 系統部署與更新說明

本版本（V19.3）已將所有邏輯整合至單一的 `app.py` 檔案中，無需額外安裝其他依賴庫或修改資料庫結構：

1. **直接覆蓋**：請將產出的 `app.py` 程式碼完全覆蓋至您現有的 Streamlit 執行目錄中。
2. **自動載入**：系統會自動讀取您原有的 `stock_dict.json` 與 `industry_db.json`，原有的個股清單、自訂名稱與 AI 產業百科皆會完美保留。
3. **快取清理**：若畫面未即時更新，可在側邊欄點選 **「一鍵全百科重置」** 或在瀏覽器中重整頁面，以強制清除舊版 YFinance 的殘留緩存。
