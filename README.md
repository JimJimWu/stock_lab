# 🐎 黑馬雷達：量化回測自動同步系統說明手冊 (V1.0)

本系統是一套具備「自動記憶」與「雲端同步」能力的量化交易輔助平台。透過 `app.py` (網頁端) 與 `auto_scan.py` (自動化端) 的雙軌協作，實現 24 小時無間斷的訊號追蹤與勝率回測。

---

## 🏗️ 一、 系統架構圖解
系統採用「GitHub 倉庫」作為唯一的**數據真理來源 (Single Source of Truth)**：
1. **自動化端 (GitHub Actions)**：每 30 分鐘自動掃描，發現訊號後推播至 Discord，並將紀錄寫入 `signal_history.csv` 回傳至倉庫。
2. **網頁端 (Streamlit Cloud)**：自動監聽倉庫變動，即時同步最新的 CSV 回測日誌供使用者下載與分析。

---

## 🚀 二、 自動化運作流程 (SOP)

### 1. 訊號觸發與紀錄
* **資料來源**：`yfinance` 抓取即時 K 線。
* **處理核心**：`log_signal_to_csv` 引擎。
* **淨化邏輯**：自動剝離括號，將 `3163 (波若威)` 淨化為純名稱 `波若威`。

### 2. 雲端同步機制
* **GitHub 機器人**：完成掃描後，自動執行 `git commit`。
* **時區鎖定**：Commit 訊息強制使用台灣時間 (`Asia/Taipei`)。
* **防止迴圈**：使用 `[skip ci]` 標籤，確保資料更新不會導致重複觸發掃描。

---

## 📊 三、 回測資料庫規格 (CSV)
檔案名稱：`signal_history.csv`
編碼格式：`UTF-8 with BOM` (支援 Excel 直接開啟無亂碼)

| 欄位名稱 | 說明 | 範例 |
| :--- | :--- | :--- |
| 日期時間 | 訊號發生的精確時間 (台灣時間) | 2026-05-15 14:30:00 |
| 股票代號 | 4 位或 6 位數字代碼 | 3595 |
| 股票名稱 | 純淨的中文名稱 (無代號重複) | 山太士 |
| 觸發價格 | 觸發訊號當下的成交價 | 125.5 |
| 核心訊號 | AI 判定的核心多空狀態 | 強勢多頭 |
| 技術與量能 | 詳細的 RSI、成交量比等指標 | RSI: 57.6 | 成交量比: 1.2x |

---

## 🛠️ 四、 資料維護與髒資料清洗 SOP

當系統中出現測試數據或錯誤紀錄時，請遵循以下**「安全覆蓋流程」**：

1. **下載 (Download)**：從 Streamlit 網頁側邊欄下載最新的 `signal_history.csv`。
2. **清洗 (Clean)**：使用 Excel 開啟，手動刪除不要的列，並確保標頭欄位正確。
3. **覆蓋 (Upload)**：
   * **方法 A (推薦)**：直接將乾淨的 CSV 拖入 GitHub 專案網頁首頁進行 `Upload files`。
   * **方法 B**：使用網頁端側邊欄的「上傳覆蓋」功能。
4. **生效**：上傳後約 1 分鐘，網頁端將自動完成同步。

---

## ⚠️ 五、 關鍵開發備註
* **防亂碼機制**：網頁端下載必須使用 `open(file, "rb")` 二進位讀取，以保留 BOM 識別標籤。
* **自動重新整理**：網頁端手動掃描後，系統會自動執行 `st.rerun()` 刷新 UI 狀態。
* **權限設定**：GitHub Actions 必須開啟 `permissions: contents: write` 才能順利回傳資料。

* 🏹 **歷史連續鎖碼偵測中心 (V42.0 全新核心)**  
  本功能是雷達系統中用來過濾「單日騙線雜訊」的終極武器。透過自動調閱雲端回測資料庫 (`signal_history_backtest.csv`)，精準抓出在最近 N 個交易日中，**連續觸發「完全相同」核心訊號**的極端標的（例如連續 3 天皆為「💎大戶惜售」或「🚨強勢突破」），代表主力籌碼具有高度延續性。

  * **去雜訊機制**：無論您在盤中手動按了幾次大掃描，或是背景機器人定時推送，系統皆會自動啟動過濾邏輯，**每天每檔股票僅保留「最後一次」的最新狀態**，確保多日比對的絕對精準。
  * **最佳應用場景**：
    1. **盤前沙盤推演**：建議於每日早上開盤前查看「最新盤前偵測」面板。若發現某標的連續多日大戶惜售，代表散戶已被洗淨且莊家拒絕降價，可列為今日開盤重兵盯盤對象。
    2. **盤後籌碼覆盤**：收盤後可利用「歷史時光機」分頁，自由選定過去的基準日往回推算，檢視過去特定區間的連續鎖碼股，藉此優化波段選股勝率。
